# quicknote

a simple, open-source mac app for taking quick notes.

forked from [freewrite](https://github.com/farzaa/freewrite) — same quiet writing surface, aimed at capturing thoughts fast instead of long freewriting sessions.

## get running

- clone repo
- open in xcode
- click build
- done — you're up and running

make changes on a pr and i'll run on my end :).
