# quicknote

a simple, open-source mac app for taking quick notes.

forked from [freewrite](https://github.com/farzaa/freewrite) — same quiet writing surface, aimed at capturing thoughts fast instead of long freewriting sessions.

Type one to six `#` characters and Space to start a live heading. Other Markdown renders when you leave its line. Move back to a line to edit its source, or press Shift–Cmd–M to show the whole note’s source. Notes still save as plain `.md` files. Type `-` on an empty line to start a bullet, Return to add another, or Return on an empty bullet to leave the list. Type `\-` for a literal dash.

## get running

- clone repo
- open in xcode
- click build
- done — you're up and running
