# quicknote

a simple, open-source mac app for taking quick notes.

forked from [freewrite](https://github.com/farzaa/freewrite) — same quiet writing surface, aimed at capturing thoughts fast instead of long freewriting sessions.

Write Markdown on the active line. Quick Note renders it when you press Return or move away, and shows the source again when you return to edit. Notes still save as plain `.md` files. Press Shift–Cmd–M to show the whole note’s source. Type `-` on an empty line to start a bullet, Return to add another, or Return on an empty bullet to leave the list. Type `\-` for a literal dash.

## get running

- clone repo
- open in xcode
- click build
- done — you're up and running
