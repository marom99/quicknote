# quicknote

a simple, open-source mac app for taking quick notes.

forked from [freewrite](https://github.com/farzaa/freewrite) — same quiet writing surface, aimed at capturing thoughts fast instead of long freewriting sessions.

The editor renders Markdown as you type and still saves plain `.md` files. Press Shift–Cmd–M to edit the source. Type `-` on an empty line to start a bullet, Return to add another, or Return on an empty bullet to leave the list. Type `\-` for a literal dash.

## get running

- clone repo
- open in xcode
- click build
- done — you're up and running

make changes on a pr and i'll run on my end :).
